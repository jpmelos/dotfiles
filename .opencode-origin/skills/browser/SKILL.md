Use the `agent-browser` CLI tool to interact with websites.

To learn how to use the tool, call `agent-browser -h`.

If you need to search the web to find URLs to use with `agent-browser`, you may
use the `WebSearch` tool.

Follow these instructions, plus any additional instructions in the user message.
